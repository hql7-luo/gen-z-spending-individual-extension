# Gen Z 消费：课程项目的重新核对

UW IS 445 课程小组项目（2025）的个人扩展

- **1,700** 条财务记录，18-27 岁
- **0.03** 收入与消费的相关系数
- **50.6%** 消费高于收入

两个数字都与课程原报告一致。用 SQLite 重建，并用 Python 独立核对。

## 重新核对的发现

1. **财务数据看起来是随机生成的.** 14 个数值列都在整数上下限之间均匀分布，例如收入从 1,501 到 7,994 美元；任意两列的相关系数都不超过 0.06。相关系数接近 0，反映的是数据的生成方式，而不是 Gen Z 的消费规律。

2. **消费高于收入，主要由收入高低决定.** 各收入水平的平均消费都在 4,800 美元左右，所以收入低于中位数的人中有 88% 消费高于收入，而收入不低于中位数的人中只有 14%。

3. **不同年龄组的购物偏好基本相同（合成数据）.** 在另一份合成购物数据中，18-27 岁与 28-70 岁在支付、配送、购买频率和品类四项比较上，经 Holm 校正后有 0 项存在差异。

各收入十分位中消费高于收入的比例: D1 100%, D2 99%, D3 94%, D4 84%, D5 61%, D6 39%, D7 21%, D8 8%, D9 0%, D10 0%

## 如果有真实客户数据，我会这样做

1. 用真实客户的实际购买行为分群（品类结构、复购、对过往促销的反应），而不是只按收入或年龄。 本数据中收入与消费几乎无关（r = 0.03），每个收入十分位的平均消费都在 4,660 到 4,866 美元之间。

2. 先用一个统一方案，再在小范围内一次只测试一个变化（价格、运费、促销时间），有效再推广。 在合成购物数据中，支付、配送、购买频率、品类四项比较经校正后，18-27 岁和 28-70 岁之间有 0 项存在差异（Cramer's V 最大 0.04）。

3. 在基于数据提出建议之前，先确认数据来源，并检查它的分布是否合理。 简单的分布检查显示，每个数值列都在整数上下限之间均匀分布，任意两列的相关系数都不超过 0.06。

说明：两份数据相互独立，未做合并；金额单位为美元，未注明周期；结论只描述这两份数据，不代表真实的 Gen Z 消费者。
